# Stream Extractor

A minimal web app that extracts the direct stream URL from a video link and plays it in a clean, ad-free player.

## Setup

```bash
pip install -r requirements.txt
python app.py
```

Then open **http://localhost:5000** in your browser.

## Usage

1. Paste any supported video URL (YouTube, Twitch, Vimeo, Twitter/X, etc.)
2. Click **Extract**
3. The stream loads in a clean HTML5 player — no ads, no distractions

## Supported sites

Powered by [yt-dlp](https://github.com/yt-dlp/yt-dlp), which supports 1000+ sites.
